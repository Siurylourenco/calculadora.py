# 🧮 Calculadora Simples com Streamlit

Este é um projeto de estudo criado por mim como parte do meu processo de aprendizado em Python e Streamlit.  
A calculadora executa operações matemáticas básicas (soma, subtração, multiplicação e divisão) com uma interface amigável feita com Streamlit.

## 🎯 Objetivo do Projeto

Criar uma aplicação web simples para treinar os seguintes conceitos:

- Criação de funções em Python
- Uso de parâmetros e retorno de funções
- Estruturas condicionais (`if`, `elif`, `else`)
- Escopo de variáveis
- Interface gráfica simples com Streamlit
- Deploy de aplicações no Streamlit Cloud

## 🛠️ Recursos Utilizados

- **Python 3.10+**
- **Streamlit** para construção da interface web
- `requirements.txt` para controle de dependências

## 🧠 Conceitos de Python aplicados

- **Funções com parâmetros**: A calculadora recebe dois valores e uma operação como entrada.
- **Retorno de funções**: A função principal retorna o resultado da operação.
- **Escopo de variáveis**: Uso de variáveis locais dentro da função.
- **Estruturas condicionais**: Verificação de qual operação executar.
- **Tratamento de exceções simples**: Evita divisão por zero.
